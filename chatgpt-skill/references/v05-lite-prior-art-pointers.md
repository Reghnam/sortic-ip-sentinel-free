# Lite Prior Art / FTO High-Level Signals (v0.5.1-free)

**This is not a search and not clearance.** Pointers only. Escalate to qualified counsel for real work.

## Public places to look (you, or counsel, later)

- USPTO PatFT / AppFT
- Google Patents
- Espacenet
- WIPO PATENTSCOPE
- Lens.org

Search your own high-level problem + technical field. Do not paste secret embodiments into public search boxes.

## Software / AI red flags (hygiene, not a ruling)

- Claims that are only "apply ML to X".
- Abstract idea + generic computer.
- Common pipeline steps with no specific technical effect described.

If those show up in **your** draft claims or pitch, hold them back and talk to counsel. This skill will not say "you are clear" or "you should file".
