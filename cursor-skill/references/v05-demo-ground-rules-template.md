## Ground Rules Script (say or send before diving in)

"Before we start: this is confidential evaluation material only. We have filed provisionals covering key technical aspects. Details beyond the high-level overview are under NDA if we move forward. Please do not record, photograph, copy, or share specifics without agreement. At the end we will confirm what can be retained. Questions?"

## Quick Pre-Demo Checklist (7-10 days)

- [ ] Contribution / inventorship log updated for humans involved.
- [ ] Provisional(s) filed or updated covering what will be shown (enablement level).
- [ ] Demo-mode version created (masked values, limited scope, no production data).
- [ ] NDA ready or confirmed existing one covers purpose.
- [ ] Agenda agreed. Scope limited.
- [ ] Logging plan in place (what shown, attendees, screenshots).
- [ ] All materials watermarked "Confidential — evaluation only".
- [ ] Access: remote preferred; no unescorted guest accounts, no USB, no recordings unless pre-agreed and logged.
- [ ] Post-session: destruction/return protocol agreed.
- [ ] Internal team briefed on safe vs unsafe statements.
