# Investor / Partner Demo Hygiene Playbook (SorticAI Free Tier)

**Version:** v0.5-free (sanitized for public free-only sentinel)
**Free only · Guarantees:** none · **Not legal advice**

**Core principle:** File (or have filed) appropriate provisionals *before* significant external exposure. Use staged disclosure. Protection builds trust and enables productive conversations.

## 1. Staged Disclosure Ladder (high-level)
1. **Initial contact / teaser** (no NDA often required): High-level "what it is", problem it solves, qualitative benefits, "we have filed provisionals covering key technical aspects; details under NDA if serious".
2. **Early pitch / deck** (patent pending marking): Block architecture diagram, high-level pipeline/flow (investor-level steps only), no critical parameters, exact recipes, full source, or sensitive internals.
3. **Deeper technical walkthrough** (signed NDA required): More architecture, sample (scrubbed) data, performance metrics. Log what was shown.
4. **Live demo or pilot access** (NDA + controls): Demo-mode / masked values, escorted/remote, no recording/USB/guest network, pre-agreed agenda, post-visit destruction or return of materials, watermark "Confidential — evaluation only".

**Sources referenced (high-level):** EPO Guidelines (technical effect for CII), USPTO 2025 AI inventorship/guidance summaries, WIPO pre-filing disclosure principles. Always consult qualified counsel for your jurisdiction and facts.

## 2. Patent Presentation Template (Safe for Early Exposure)
Use this structure for decks or overviews (modeled on proven sanitized examples):

**Slide / Section 1: What it is (1-2 sentences)**
- High-level description of the system/process + the valuable outcome.

**Slide / Section 2: Why a system / technical problem**
- The real-world problem it addresses.
- Why current approaches fall short (without revealing your secret sauce).

**Slide / Section 3: High-level architecture (block diagram only)**
- Major components and data flow.
- Omit exact parameters, proprietary algorithms, full source, or sensitive setpoints.

**Slide / Section 4: Pipeline / flow at investor level**
- 4-8 high-level steps (e.g., "ingest → process with novel control → output actionable result").
- Qualitative benefits + any public or non-sensitive metrics.

**Slide / Section 5: Exposure & next steps**
- "Key technical aspects covered by filed provisionals."
- "Detailed embodiments and implementation under NDA."
- Call to action for deeper discussion.

**Last slide (always):** Full disclaimer (see below).

**Tips from cases:**
- POLYREC example: Show visible sequences/setpoints only in demo mode; hold exact values until NDA + provisional coverage confirmed.
- Nidara-style: Explicit "what can go in deck/private repo now vs. wait for NDA".

## 3. Pre-Demo / Pre-Pitch Checklist (7-10 days out)
- [ ] Confirm inventorship / contribution log completed (see separate template).
- [ ] File or update provisional(s) covering the aspects you will show (enablement: problem, solution, implementation details sufficient for reproduction by skilled person).
- [ ] Create "demo mode" version (masked/scrubbed values, limited functionality, no production data).
- [ ] Prepare NDA (or confirm existing one covers purpose).
- [ ] Agenda agreed in advance; limit scope.
- [ ] Logging plan: what will be shown/shown-to, screenshots taken, attendees.
- [ ] Watermarks / confidentiality markings on all materials.
- [ ] Access controls: remote preferred; no unescorted guest accounts, no USB, no recordings unless explicitly allowed and logged.
- [ ] Post-session: destruction/return protocol for any materials.
- [ ] Internal team briefed on what is / is not safe to say.

## 4. Ground Rules Script (for the other side, before we start)
"Before we dive in: this is confidential evaluation material. We have filed provisionals on key technical aspects. Details beyond the high-level overview are under NDA. Please do not record, photograph, or share specifics without agreement. At the end we'll confirm what can be retained."

## 5. Sample Run-of-Show (Live Session)
1. Story / context (2-3 min)
2. Ground rules + disclaimer (30s)
3. High-level overview + architecture (5 min)
4. Demo (masked) + qualitative results (5-8 min)
5. Business / next steps (3 min)
6. Hold on disclaimer + Q&A frame (what is safe to answer now vs. under NDA)

## 7. Q&A Armor — Common Questions + Safe Frames
- "Can you share the exact [parameters / code / model]?" → "Those internals are proprietary know-how protected as trade secrets and covered in our filings. We can discuss high-level approach under NDA."
- "Have you filed patents?" → "We have filed provisionals on key technical aspects and are following standard best practices for protection."
- "What prior art did you find?" → "We performed internal diligence. Full prior art and FTO work is done with qualified counsel."

**Remember:** You control the scope. It is okay (and smart) to say "I can't go deeper without an NDA / without counsel present."
