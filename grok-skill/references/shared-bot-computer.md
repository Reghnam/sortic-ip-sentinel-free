# Moved skill lines

- **Shared Bot computer is account-wide.** All of your Bots share files, browser sessions, and app logins. Treat anything on that computer as available to every Bot you run. Isolation between users is strict; isolation between your Bots is not. Livestream/invite copy that each Bot has its own computer is marketing, not isolation. **Screens are separate work surfaces, not security boundaries.** Do not use separate Bots as a vault. Isolated credentials need a **dedicated user**. Delete Bot ≠ wipe computer files/sign-ins. Enterprise terminate-computer keeps the durable disk (next session remounts it). **Bot-to-Bot DM / group chat is a disclosure hop.** Auto Review does not review memory writes / most settings changes. **Grok Bot computers run in the United States today** — not on-prem, not BYO image, not inside your perimeter; holdbacks on that computer are US-hosted. Recreate (image update / policy) can drop in-computer sign-in sessions; terminate-computer still keeps the durable disk. **Sign-out ≠ wipe:** Claude Code 2.1.272 keeps claude.ai-synced skills on disk until `cleanupPeriodDays`, then trash. **v2.1.273+** signed-in terminal sessions download to `~/.claude/skills/synced/` then check claude.ai **~every 10 minutes** and apply add/edit/disable **without a restart** (synced copies are **read-only** and download **on invoke**; **bare mode** and **safe mode** skip sync) (v2.1.275 also plugins; opt-out `syncClaudeAiSkills` / `syncClaudeAiPlugins`). **Custom commands have been merged into skills** (`.claude/commands/foo.md` ≡ `.claude/skills/foo/SKILL.md` → `/foo`; existing commands keep working). **Stacked slash-skills** load the first skill plus up to five more (`/a /b /c do X` — trailing text is `$ARGUMENTS` to each); chaining this skill with a send/publish skill is a disclosure multiplier. v2.1.277: a project with no `CLAUDE.md` reads `AGENTS.md` instead — that file is a hop if it holds method. `/config` can load **both** AGENTS.md and CLAUDE.md — both are hops. Grok also discovers user-level `~/.agents/commands/`. A marketplace skill that lets a Bot take jobs or get paid is access grant + send + computer-use. claude.ai enablement now syncs skills to Cowork/cloud; `CLAUDE_CODE_SYNC_SKILLS=1` downloads to `~/.claude/skills/synced/` (prefixed `/anthropic-skills:`). Local `~/.claude/skills/` still does not auto-sync to Cowork. Each enablement is a publish. `disable-model-invocation` also blocks scheduled-task skill prompts (v2.1.196+). Synced skills: no local `!` commands; frontmatter sanitized. **Desktop-egress is a CDN, not a vault** (Settings → Updates → Update Grok Bot's Computer FIRST, then Settings → Computer → Route Computer traffic through this desktop; reverse order errors "wasn't provisioned with the egress tunnel"; laptop closed stops routing; holdbacks on that desktop see Bot traffic). **Ownership-pass is access grant + hop** (Bots on one account hand off tasks on the shared computer; decline unnamed). **No Legacy Privacy Mode** (Grok Bot requires cloud storage; training opt-out follows the Cursor account, not a vault). Do not add `allowed-tools` write grants **or** `disallowed-tools` to this skill. **Grok `allowed-tools` does not grant or restrict** (ignored for tool policy — not a vault or a lock). Anthropic **`allowed-tools` / `disallowed-tools` are one-turn** — grant and restriction both clear on the next message; cannot remove `EndConversation` if other tools remain. One-turn grant-clear / restriction-clear is not a vault. **Dist-path:** Claude Code accepts all frontmatter; claude.ai / Skills API / `package_skill.py` only `name, description, license, compatibility, metadata, allowed-tools` — extra keys error. That is why `claude-skill/` is name+description only. **Skill security scanning is not a vault** (claude.ai/Cowork only; misses Skills API, already-uploaded skills, CMEK/ZDR/HIPAA orgs). Custom claude.ai Skills are per-user and do not auto-sync; Anthropic settings enablement may — neither is a vault. Listing truncate: combined description + when_to_use 1536 chars. Skill listing budget is 1% of context. `context: fork` is a hop (subagent does not inherit this skill unless listed).
