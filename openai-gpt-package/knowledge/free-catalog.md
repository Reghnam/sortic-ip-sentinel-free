## Standard free help offers

| Offer | What you deliver |
|-------|------------------|
| Show / hold map | Safe to show live · keep private · wait for NDA before more detail |
| Session ground rules | Short “before we start” for the other side |
| Pre-meeting / pre-demo pack | Agenda, cover note, what you will / won’t cover |
| Slides / deck help | Walkthrough, show/hold, footers `N / TOTAL`, **disclaimer as last slide** |
| Standalone disclaimer | Not legal advice, not counsel, confidentiality, ownership, fundraising caution if needed |
| Live run-of-show | Story → ground rules → demo → business → hold on disclaimer |
| Situation summary for later | Export only when asked (and enough context) — still not legal advice |
| Hold-back checklist | Decks, repos, recordings, chats, leave-behinds |
| Q&A armor | Likely questions + safe frames + what to leave for counsel |
| **Investor / Partner Demo Hygiene Playbook (priority for patent presentation / safe demo)** | Staged disclosure ladder; patent presentation template (high-level problem/solution narrative + block architecture + pipeline steps only); pre-demo checklist (NDA inventory, demo-mode creation, access lockdown, logging, watermarking); ground-rules script; run-of-show; sample last-slide disclaimer. Sources referenced (high-level): EPO Guidelines G-II 3.3.1, USPTO 2025 AI guidance, WIPO. |
| AI/Agentic Invention Contribution Log | Simple table template: Date | Human contributor | Specific contribution (problem framing, prompt design/selection/refinement, recognition of result) | Evidence pointer. Supports inventorship hygiene (human conception required). |
| Provisional Readiness Checklist | Enablement elements (technical problem, specific implementation + effect/metrics, diagrams/pseudocode, embodiments); timing (file before exposure); follow-on provisionals; jurisdiction note (US grace vs absolute novelty). |
| Code / Output Provenance + Holdback Audit | Prompts/checklist for scanning build artifacts for AI-generated sections; recommended masking/redaction for demos; “what was shown to LLM” log. |
| Trade Secret ID Matrix + Secrecy Measures | Asset | Why TS candidate (not easily reverse-engineerable?) | Current secrecy steps (marking, access logs, NDAs, no public AI for core work) | Gaps. List of reasonable measures. |
| Lite Prior Art / FTO High-Level Signals | Quick public search pointers (USPTO, Espacenet, Google Patents, WIPO PATENTSCOPE); red flags for software/AI (abstract claims, common techniques); “this is not a search / not clearance” language. When to escalate. |
